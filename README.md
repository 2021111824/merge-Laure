# 合成散文集

这个目录是适合公开部署的版本，可以直接用于 GitHub Pages、Cloudflare Pages、Vercel 等静态托管平台。

直接双击 `index.html` 就可以运行。

## 你需要准备几张图片

建议先准备 **11 张**，对应从小到大的 11 个合成等级。

当前游戏会按编号自动加载素材：

- `assets/1.*` 到 `assets/11.*`
- 优先使用当前目录里存在的同编号图片，比如 `1.jpg`、`2.png`

如果你替换了某一张图，刷新页面后会重新读取最新文件。

## 图片建议

- 格式：优先 `PNG`，也支持 `JPG/JPEG/WEBP`
- 画布：建议正方形，比如 `256x256` 或 `512x512`
- 背景：最好透明
- 主体：尽量放在中央
- 风格：11 张图最好风格统一

## 当前状态

如果 `assets` 目录里还没有图片，游戏会先显示默认占位圆形，不影响试玩。
